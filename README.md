# pre-entrega-modulo4-sql
Pre-entrega 4 de Coderhouse - Consultas multicapa para análisis de negocio


**Proyecto:** Consultas multicapa para análisis de negocio

Archivo SQL con tres consultas para analizar los ingresos por categoría, identificar clientes sin compras y conocer los productos más comprados por cada cliente.

## Ejecución

1. Tener cargadas las tablas del Módulo 4 en el esquema 'practica_m4' de PostgreSQL.

2. Conectarse a la base de datos desde pgAdmin o DBeaver.

3. Abrir y ejecutar el archivo 'pre-entrega-modulo4.sql'.
